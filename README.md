# Earnings Atelier

This project is a dashboard for viewing and comparing quarterly earnings, IR documents, and stock price trends across multiple companies using Supabase and Cloudflare Workers.

It helps users monitor financial performance and summarize corporate disclosure data in a simple browser-based interface.

複数企業の決算情報を表示するダッシュボードです。左側の会社メニューから対象企業を切り替え、Supabaseに登録した業績推移、四半期内訳、公式IR PDFを確認できます。
