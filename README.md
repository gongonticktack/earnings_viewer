# Earnings Atelier

複数企業の公式IR資料をもとに、四半期単独の営業収益、営業コスト、営業利益、親会社所有者帰属利益を表示するダッシュボードです。左側の会社メニューから表示対象を切り替えられます。

通期資料がある企業については、前年度の営業利益から当年度の営業利益までの変化をウォーターフォールで表示します。営業費用の内訳と投資活動キャッシュフローも確認できます。

現在は次の企業に対応しています。

- トヨタ自動車
- NTT
- 東芝
- ソフトバンク

各社とも直近2年度分の四半期データを表示します。

## ローカル表示

静的ファイルだけでデモ表示できます。`index.html` をブラウザで直接開いてください。

ローカルサーバーを使う場合は、Python がインストールされていれば次のコマンドでも表示できます。

```powershell
python -m http.server 5173
```

ブラウザで `http://localhost:5173` を開いてください。

## Supabase 接続

1. Supabase プロジェクトを作成します。
2. SQL Editor で直下の `schema.sql` を実行します。
3. `supabase-config.json` に接続情報を設定します。

既存環境でも、項目追加後は `schema.sql` を再実行してください。`alter table ... add column if not exists` で不足列だけを追加します。

テーブル名は他アプリとの同居を考慮して `earn_` 接頭辞で統一しています。以前の接頭辞なしテーブルは `schema.sql` 実行時に削除されません。

ブラウザから Supabase REST API を呼び出すため、匿名キーにこのアプリ用テーブルの追加・更新権限を付与しています。個人用・試作用の構成です。インターネットへ公開する場合は、認証を追加して書き込みポリシーを制限してください。

## 更新タイミング

定期実行ジョブは使用しません。ページを開いたときと会社を切り替えたときに、選択中の会社だけを確認します。

- 前回取得から3か月未満: DBに保存済みのデータを表示します。
- 前回取得から3か月以上、または初回取得: JSに同梱済みのデータをDBへ保存してから表示します。
- `今すぐ再取得`: 3か月の経過を待たず、表示中の会社だけをDBへ再保存します。

画面下部の `Sync Log` には、DB読込、鮮度確認、DB保存の結果が残ります。失敗時はエラーになった段階とレスポンス内容を確認できます。

## データの扱い

- 現在の数値はランダムなサンプルではなく、公式IR資料をもとにJSへ登録したデータです。ただし、公式サイトからのリアルタイム自動取得ではありません。
- 出典は [トヨタ自動車 決算資料](https://global.toyota/jp/ir/financial-results/)、[NTT 決算説明会資料](https://group.ntt/jp/ir/library/presentation/financial/)、[東芝 財務・業績](https://www.global.toshiba/jp/ir/corporate/finance.html)、[ソフトバンク 決算短信](https://www.softbank.jp/corp/ir/documents/financial_reports/) です。
- 表示単位は百万円です。カードでは十億円へ変換しています。
- 公式資料の累計値から前四半期累計を差し引き、四半期単独値を保存しています。
- 営業コストは `営業収益 - 営業利益` の算出値です。
- キャッシュフロー欄には、前期末現金から今期末現金までの増減をウォーターフォールで表示します。営業活動CF、投資活動CF、財務活動CFと、為替影響などのその他調整を確認できます。
- 株価欄には、TradingViewから読み込んだ週足チャートを表示します。非上場の東芝は株価チャートを表示しません。

現在はトヨタ FY2025〜FY2026、NTT FY2024〜FY2025、東芝 FY2024〜FY2025、ソフトバンク FY2024〜FY2025 の登録済み四半期データをブラウザからDBへ保存します。ブラウザから公式IRページを直接取得するとCORS制限を受けるため、新しい決算発表を完全自動で解析して追加する場合はサーバー側の処理が必要です。
